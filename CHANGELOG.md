# Changelog

## 0.1.7 - Unreleased

- Added typed flex growth, shrinking, basis, wrapping, self-alignment, and
  axis-specific overflow properties to `respo_style`.
- Added typed row and column gaps, logical insets, minimum height,
  `text-overflow`, `color-scheme`, and `accent-color` properties.
- Added dynamic, small, large, logical viewport, and container query units to
  `CssSize`.
- Added output regression tests for the new properties and units.
